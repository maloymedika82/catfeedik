# Текущее состояние

Ветка разработки использует React/TypeScript/Vite/Tailwind + FastAPI/SQLAlchemy + PostgreSQL17/PostGIS + Redis/Celery. Видео хранятся на VPS/локальном сервере, R2 не используется. Бот animalfeedikbot, Owner ID 2022054034 задаётся сервером и требует подписи Telegram. Присланный API-ключ не сохранялся и не использовался; новый требуется добавить приватно после отзыва старого.

Реализованы мировая карта Leaflet/OpenStreetMap, локальный GeoNames для ближайшего города, FFmpeg H264/AAC/30fps/720p и постер без метаданных, очередь Celery с восстановлением из БД, AnyModel vision adapter с проверкой структурированного ответа, ручная/AI-модерация, транзакционные поинты, точные SHA256-дубликаты, городская публичная лента и идемпотентные лайки. Денежные функции отключены. Тестовые настройки development: 20 МиБ, радиус100м, точность50м; production требует явных значений.

Проверки: production build; 39 тестов PostgreSQL, включая реальный FFmpeg/непотоковый MP4 и потоковый WebM без Duration, сохранение приватности координат, удаление метаданных, AI HTTP mocks и повтор без перекодирования/двойного начисления. Сквозной Chromium-тест: виртуальная камера -> загрузка -> настоящие Celery/Redis/FFmpeg -> REVIEW -> ручное решение тестового Owner -> маркер -> лента -> лайк. Тесты выполняются на временной БД/схемах, не на данных пользователя. Внешние OSM-тайлы заменены явно тестовыми в проверке; настоящие тайлы и AnyModel заблокированы сетью среды и не верифицированы. Реальные Telegram iOS/Android и Windows-скрипты ещё не проверены на устройствах.

Остаются production-развёртывание/HTTPS, настоящий ключ и контракт AnyModel, апелляции, расширенный антифрод, спонсоры/задания, английская локализация, полная админка, уведомления, финансовые функции после отдельного включения, миграции, мониторинг и резервирование с проверкой восстановления. Готовым production-MVP этот этап не считается. Исходное ТЗ сохранено в specification.txt; изменения хранения и тестовых параметров авторизованы пользователем.
