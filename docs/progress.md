# Текущее состояние

Готова первая связка React/TypeScript Mini App + FastAPI + PostgreSQL17/PostGIS. Redis запущен, очередь Celery ещё не реализована. Все метрики/профили читаются из БД; примеры рейтинга и спонсоров убраны. Настоящие Telegram/R2 credentials отсутствуют; реальные авторизация/передача видео не проверены.

Проверки текущего изменения:
- npm run build: проходит.
- API: 15 тестов на PostgreSQL в изолированных схемах, включая конкурентное одобрение одного кормления.
- Браузер: 10 сценариев API + React, сохранение профиля после reload, выход, мобильная ширина, клавиатура, reduced motion. Ошибок JS нет.
- Виртуальная камера Chromium: разрешения камеры/микрофона/GPS, запись, blob-предпросмотр, пересъёмка, автозавершение через 15 секунд (фактическая тестовая запись 14.96 с), закрытие. Реальные устройства ещё не проверены.
- SL UI: matte-dock-navigation / dock-navigation, source-markers-present, без недостающих классов/SVG; это не сертификат доступности или полного визуального совпадения.
- PostgreSQL17 + PostGIS3.5 и Redis отвечают на проверки.

Следующий этап: FFmpeg/Celery проверка и нормализация видео, AI-адаптер после выбора провайдера, публичная лента и лайки, резерв денежных бонусов, апелляции. Серверное одобрение пока ручное; администратор должен проверить исходное видео, длительность/кормление и локацию. Production-деплой запрещено считать готовым по этим локальным проверкам.
