# Текущее состояние

Готова первая связка React/TypeScript Mini App + FastAPI + PostgreSQL17/PostGIS. Redis запущен, очередь Celery ещё не реализована. Все метрики/профили читаются из БД; примеры рейтинга и спонсоров убраны. Настоящий Telegram-бот ещё не подключён. По решению пользователя R2 заменён приватным хранилищем на сервере; заполненный локальный .env пользователя не доступен агенту.

Проверки текущего изменения:
- npm run build: проходит.
- API: 25 тестов на PostgreSQL в изолированных схемах, включая конкурентное одобрение одного кормления.
- Браузер: 10 сценариев API + React, сохранение профиля после reload, выход, мобильная ширина, клавиатура, reduced motion. Ошибок JS нет.
- Виртуальная камера Chromium: разрешения камеры/микрофона/GPS, запись, blob-предпросмотр, пересъёмка, автозавершение через 15 секунд (фактическая тестовая запись 14.96 с), закрытие. Реальные устройства ещё не проверены.
- SL UI: matte-dock-navigation / dock-navigation, source-markers-present, без недостающих классов/SVG; это не сертификат доступности или полного визуального совпадения.
- PostgreSQL17 + PostGIS3.5 и Redis отвечают на проверки.
- Локальная загрузка: потоковый приём, проверка размера/типа/места, атомарное сохранение без перезаписи, hash-проверка повторной передачи, уборка временных файлов, авторизация просмотра и Range. Пройдены тесты отказа в доступе и заполненного диска.

Следующий этап: FFmpeg/Celery проверка и нормализация видео, AI-адаптер после выбора провайдера, публичная лента и лайки, резерв денежных бонусов, апелляции. Серверное одобрение пока ручное; администратор должен проверить исходное видео, длительность/кормление и локацию. Production-деплой запрещено считать готовым по этим локальным проверкам.

Сквозная проверка локального хранилища: виртуальная камера → авторизованный PUT реального записанного видео → REVIEW → история профиля; просмотр с Range по cookie, анонимный отказ, запрет Vite на .local, очистка staging. Проверка использует временную БД/каталог и тестовые лимиты, не настройки пользователя.
