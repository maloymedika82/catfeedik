# Текущее состояние

Ветка разработки использует React/TypeScript/Vite/Tailwind + FastAPI/SQLAlchemy + PostgreSQL17/PostGIS + Redis/Celery. Видео хранятся на VPS/локальном сервере, R2 не используется. Бот animalfeedikbot, Owner ID 2022054034 задаётся сервером и требует подписи Telegram. Присланный API-ключ не сохранялся и не использовался; новый требуется добавить приватно после отзыва старого.

Реализованы мировая карта Leaflet/OpenStreetMap, локальный GeoNames для ближайшего города, FFmpeg H264/AAC/30fps/720p и постер без метаданных, очередь Celery с восстановлением из БД, AnyModel vision adapter с проверкой структурированного ответа, ручная/AI-модерация, транзакционные поинты, точные SHA256-дубликаты, городская публичная лента и идемпотентные лайки. Денежные функции отключены. Тестовые настройки development: 20 МиБ, радиус100м, точность50м; production требует явных значений.

Проверки: production build; 39 тестов PostgreSQL, включая реальный FFmpeg/непотоковый MP4 и потоковый WebM без Duration, сохранение приватности координат, удаление метаданных, AI HTTP mocks и повтор без перекодирования/двойного начисления. Сквозной Chromium-тест: виртуальная камера -> загрузка -> настоящие Celery/Redis/FFmpeg -> REVIEW -> ручное решение тестового Owner -> маркер -> лента -> лайк. Тесты выполняются на временной БД/схемах, не на данных пользователя. Внешние OSM-тайлы заменены явно тестовыми в проверке; настоящие тайлы и AnyModel заблокированы сетью среды и не верифицированы. Реальные Telegram iOS/Android и Windows-скрипты ещё не проверены на устройствах.

Остаются production-развёртывание/HTTPS, настоящий ключ и контракт AnyModel, расширенный антифрод, внешние спонсорские интеграции, английская локализация, управление бюджетами/экспериментом, уведомления, финансовые функции после отдельного включения, миграции, мониторинг и резервирование с проверкой восстановления. Готовым production-MVP этот этап не считается. Исходное ТЗ сохранено в specification.txt; изменения хранения и тестовых параметров авторизованы пользователем.

## Админка, апелляции и ожидание AI

Добавлены отдельная admin.html, участники/поиск/история, идемпотентные корректировки поинтов с квитанциями, заморозка/разморозка, роли Admin (только Owner меняет), апелляции с запретом первоначальному модератору и журнал действий. Owner управляет ручным режимом; техническая обработка продолжает работать. Retry-After теперь сохраняется в БД как общее ожидание провайдера по ключу: повтор раньше срока не запускается и попытки не расходуются. Тестовые Admin доступны только в development; их сессии не работают в production. Денежные операции остаются выключенными.

В браузере на временных данных проверены корректировка баланса, потеря ответа обновления профиля без повторной операции, заморозка/разморозка, журнал, Owner-пауза AI и пользовательская апелляция с другим Admin. Скриншоты admin-desktop/mobile показывают тестовые данные. Реальная доступность AnyModel по-прежнему не подтверждена; внешние сбои не считаются исправленными.

Итоговая проверка этого этапа: 55 тестов на PostgreSQL прошли, production-сборка двух страниц (index.html/admin.html) проходит, расширенный сквозной браузерный сценарий прошёл на временных данных.

## Спонсоры, задания и ручное подтверждение

Добавлены опубликованные/скрытые партнёры, задания со сроком и наградой, пользовательские заявки и история, Owner-проверка с причиной, статистика участников и журнал. Баллы выдаются транзакционно один раз за задание, количество кормлений не меняется. Денежных выплат и автоматической проверки внешних сервисов нет.

Проверка: 67 тестов PostgreSQL прошли, включая роли/приватность, параллельные решения, повторы, изменение условий, сроки и закрытие задания. Production-сборка проходит.

Сквозной браузерный сценарий прошёл: Owner создаёт опубликованного спонсора и задание, участник отправляет подтверждение, Owner одобряет, баланс увеличивается на награду без увеличения числа кормлений. Одновременно повторно проверены камера, очередь, FFmpeg, карта, лайки, админка и апелляции. Все участники и данные временные.

## Условия участия и разрешения

Перед первым кормлением добавлены условия использования данных, явный пустой флажок и отказ с возвратом к карте. Согласие сохраняется сервером для конкретного профиля с версией, хешем текста и временем; повторная форма не показывается до изменения документа. Условия доступны внизу страницы. Без актуального согласия нельзя создать загрузку, загрузить содержимое или отправить незавершённое видео на обработку.

Камера/микрофон открываются только после получения GPS и города. Запрет GPS, тайм-аут и недоступность позиции имеют разные объяснения; согласие не подменяет разрешения iOS/Telegram. В браузере на временных данных проверены явное согласие, его сохранение между открытиями, отказ GPS без запроса камеры, виртуальная запись, настоящие очередь/FFmpeg и модерация. Скриншоты participation-terms-mobile/location-permission-mobile — тестовые Chromium, не реальный iPhone. Новые условия нужно дополнить реальными реквизитами оператора и политикой хранения перед массовым запуском; они не выдуманы.

Итог: 85 тестов PostgreSQL, production-сборка и расширенная сквозная браузерная проверка прошли. Реальные разрешения iOS/Telegram необходимо повторно проверить на телефоне.

## Тестовый VPS и публичный HTTPS

На Ubuntu 24.04 VPS OneDash (1 vCPU, 2 ГБ ОЗУ, 60 ГБ диск) развёрнут коммит main `5b9f19e2d8ff5ad2561c8274c421fa986d4d62a4` в `/srv/catfeedik`. Установлены Docker Engine/Compose, 2 ГБ swap и Tailscale. PostgreSQL, Redis, API, Worker, Beat и Caddy запущены, данные БД и видео находятся в постоянных Docker volumes. Секреты хранятся только в серверном `.env.production` с правами 0600; локальная `.env`, локальные данные и видео не переносились. Production API сообщает `money_enabled=false`, тестовые входы выключены, AI-модерация начинается в ручном режиме.

У VPS нет проброса стандартных публичных портов 80/443, поэтому тестовый сайт опубликован через Tailscale Funnel: https://catfeedik-test.tail16d0b1.ts.net/. Серверный Compose запускается с `compose.production.yaml` и `compose.funnel.yaml`, веб-вход доступен на сервере только через `127.0.0.1:8080`. Публичные HTTPS главная и `/api/health` прошли проверку, меню @animalfeedikbot указывает на этот URL и подтверждено через Telegram Bot API. Funnel зависит от аккаунта Tailscale и имеет ограничения полосы пропускания; перед расширением пилота нужны тесты загрузки/просмотра видео на телефонах, отдельное резервирование и проверка восстановления.
