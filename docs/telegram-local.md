# Telegram с локального компьютера, без VPS

Приложение, PostgreSQL, Redis, обработка и видео остаются на компьютере Windows. Для Telegram необходим публичный HTTPS-адрес: здесь используется ngrok, который передаёт запросы на локальный порт 5174. Это внешний посредник для трафика, не VPS и не Cloudflare. Не используйте этот режим для массового запуска: квоты и условия ngrok зависят от тарифа; компьютер и все процессы должны работать. Некоторые бесплатные туннели могут показывать промежуточную страницу — проверьте открытие на телефоне.

Закройте старые окна API, Worker и Web. В CMD, в C:\Users\admin\catfeedik, выполняйте команды по одной:

```cmd
git pull origin main
```

```cmd
scripts\start-telegram-local.cmd
```

Скрипт собирает статический интерфейс, запускает локальные службы и отключает тестовые User/Admin-входы, включая старые тестовые сессии. В .env должен быть действующий TELEGRAM_BOT_TOKEN именно @animalfeedikbot. Не отправляйте его в чат. Локальный API остаётся в режиме development с ранее выбранными лимитами; это тестирование на своём компьютере, не production.

Установите ngrok с https://ngrok.com/download/windows или через winget:

```cmd
winget install -e --id Ngrok.Ngrok
```

Откройте новую CMD после установки. Войдите в личный кабинет https://dashboard.ngrok.com и выполните предложенную там команду подключения агента с вашим authtoken только у себя на компьютере. Этот токен не является токеном Telegram; его не нужно добавлять в .env проекта или присылать в чат.

В отдельной CMD:

```cmd
ngrok http 5174
```

Оставьте окно открытым. Скопируйте HTTPS-адрес из строки Forwarding, например https://your-name.ngrok-free.app. Не копируйте localhost или адрес служебной панели.

В @BotFather: /mybots → @animalfeedikbot → Bot Settings → Menu Button → Configure menu button. Вставьте HTTPS-адрес туннеля и укажите подпись «Открыть приложение». Затем откройте @animalfeedikbot и нажмите кнопку меню. Для Owner нужен ваш реальный Telegram-аккаунт с ID 2022054034. После входа кнопка «Открыть админпанель» ведёт в ту же сессию владельца.

Проверьте на телефоне вход, камеру, геолокацию, отправку видео и ручную модерацию. Туннель не исправляет ошибки AnyModel: пока можно использовать ручную проверку. Если адрес туннеля изменился, обновите URL кнопки у BotFather. Для другого домена туннеля добавляйте только его точное имя в preview.allowedHosts в vite.config.ts; не отключайте проверку хоста полностью.

Чтобы закрыть доступ извне, остановите ngrok через Ctrl+C. После закрытия остальных окон обработка останавливается; данные Docker и локальные видео сохраняются. Не удаляйте Docker volumes.

## Альтернатива: localhost.run

Если ngrok отклоняет подключение по IP, отдельный туннель без аккаунта можно открыть через Windows OpenSSH:

```cmd
ssh -o ServerAliveInterval=30 -R 80:127.0.0.1:5174 nokey@localhost.run
```

Скопируйте выданный HTTPS-адрес *.lhr.life и установите его URL кнопки меню в BotFather. Локальный preview допускает этот домен провайдера, сохраняя проверку хоста. SSH-окно должно оставаться открытым; после переподключения адрес может измениться. Трафик проходит через localhost.run с завершением TLS у провайдера. Реальная доступность зависит от провайдера и сети.
